## Where the referral code field appears

The referral code field on Binance appears during the signup process, not after the account is created. When you open the Binance referral link, the code RMCTNB5R fills in automatically. If you navigate to the standard signup page directly, you will see an empty field labeled "Referral ID" or "Referral Code" that you can fill in manually. The field sits below the email or phone number input on the registration form. The most reliable approach is to always start from the referral link, as this guarantees the code is attached before the account exists. Once the account is created without a referral code, there is no way to retroactively add one. Many users miss this field because it is optional and easy to overlook. The form does not prevent you from proceeding without it, which is exactly why so many people skip it and lose the discount.

## Why entering the code after signup does not work

Binance ties the referral benefit to the moment of account creation. The 20% fee discount is not a coupon you apply later. It is a flag set on the account at registration. If you sign up without entering the code, the account is recorded as organic, not referred. Customer support cannot convert an existing account into a referred one after the fact. This timing requirement is the single most common reason people miss out on the discount. They create an account first, then look for where to enter the code. By that point, the window has closed. There is no settings page, no account upgrade, and no support ticket that can fix this. The system is designed this way to prevent abuse of the referral program.

## What the referral code gives you

The referral code unlocks two separate benefits: a 20% lifetime fee discount on all spot trades, which applies automatically every time you trade, and eligibility for signup bonuses of up to $100 in vouchers, released after you complete verification and hit certain trading volume thresholds. The fee discount has no expiry date as long as the account stays active. The bonus vouchers have their own terms and release conditions. The discount applies to both maker and taker fees equally. Since Binance charges 0.10% on both, a 20% discount brings the effective rate down to 0.08% on every spot trade. On a $1,000 trade, that saves $0.20 per side. The savings compound over hundreds of trades.

## Steps to apply the code correctly

- Open the Binance referral link rather than the standard homepage
- Check that the code appears in the referral field before submitting the form
- Do not clear or edit the field once the code has filled in
- Complete KYC verification to activate the account fully
- Enable 2FA with Google Authenticator for security

Following these steps ensures the discount is locked in from the first trade. If the code was entered but the discount is not showing, check that you completed KYC, as the discount may not activate until verification is done. If you skipped the code during registration, the only option is to create a new account with a different email or phone number and enter the code from the start.

## Frequently asked questions

### Can I enter the referral code after I already have a Binance account?

No. The referral code must be entered during registration. Binance does not allow retroactive application of referral benefits to existing accounts.

### Does the 20% fee discount apply to futures trading as well?

The referral discount applies to spot trading fees. Futures fee structures are governed by separate terms and may not carry the same discount.

### How do I know the code was applied to my account?

Check the fee page in your account settings. A 20% discount indicator should appear next to your trading fee tier. If it does not appear, contact Binance support with your registration details.
